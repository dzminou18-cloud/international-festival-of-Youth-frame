# International Festival of Youth Frame Generator 🎉

A professional web application for creating personalized photo frames for the International Festival of Youth 2026 in Russia.

## Features ✨

- 📸 **Upload Your Photo** - Choose any image from your device
- 🔄 **Rotate Image** - Rotate your photo in 90-degree increments
- ❌ **Remove Photo** - Clear and start over
- 💾 **Download** - Save your final composite image as PNG
- 📱 **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- 🎨 **Professional Frame** - Beautiful festival-themed decorative frame

## How to Use 🚀

1. Click **"CHOOSE YOUR PHOTO"** to select an image from your device
2. Use **"ROTATE IMAGE"** button to adjust orientation if needed
3. Drag the image to reposition it within the frame
4. Scale from corners to fit perfectly
5. Click **"DOWNLOAD CAMPAIGN PHOTO"** to save your creation

## Technologies Used 🛠️

- **Fabric.js** - Canvas manipulation library
- **HTML5** - Structure and markup
- **CSS3** - Modern styling with gradients and animations
- **JavaScript** - Interactive functionality

## File Structure 📁

```
international-festival-of-youth-frame/
├── index.html          # Main HTML file
├── styles.css          # CSS stylesheet
├── script.js           # JavaScript functionality
├── frame.png           # Festival frame overlay (required)
└── README.md           # Documentation
```

## Installation 🔧

1. Clone the repository:
```bash
git clone https://github.com/dzminou18-cloud/international-festival-of-Youth-frame.git
```

2. Navigate to the project directory:
```bash
cd international-festival-of-Youth-frame
```

3. Place `frame.png` in the root directory (the decorative frame image)

4. Open `index.html` in your browser

## Frame Image Requirements 📋

The `frame.png` file should:
- Be 350×350 pixels
- Have a transparent center area for the user's photo
- Include decorative borders and festival branding
- Be in PNG format with transparency support

## Customization 🎨

You can customize:
- **Colors** - Modify the color variables in `styles.css`
- **Text** - Edit strings in `index.html`
- **Frame Design** - Replace `frame.png` with your own design
- **Dimensions** - Adjust canvas size in `index.html` and `script.js`
